# Sistema de Bijouteria

Esta sistema esta hecho para manejar gestion de inventario y gestion de ventas en una empresa de bijouteria.

Este proyecto esta hecho usando JSP - HTML5 - CSS3 - JavaScript para la parte del Frontend y para la parte del backend esta hecho con Java - Servlet asi mismo lo conecte a una base de datos, la cual es PostgreSQL.
